# 模型引用实时生成，不保存快照

## Status

accepted（2026-10-25）

## Context

接口的请求体与响应示例可以引用数据模型。实现上有两条路：

1. 保存引用（`model_id`），发送或展示时按模型实时生成内容；
2. 保存时把模型示例展开成 JSON 快照，同时记录 `model_id` 仅用于展示。

## Decision

采用**引用 + 实时生成**。`body.model_id` 与响应示例的 `model_id` 是唯一事实来源；`body.raw` 只保留最近一次生成结果用于预览和兼容旧数据，发送与展示都重新生成。

生成取值优先级：`example` → `default` → `enum[0]` → 类型占位值；`$ref` 递归解析，设置深度上限并检测循环引用。

## Considered Options

- **快照**：实现简单、发送结果稳定，但模型修改后接口内容不会同步，且“引用”名不副实。
- **实时生成**：模型修改立即反映到所有引用处；代价是发送结果依赖当前模型，需要失效引用与循环引用处理。

## Consequences

- 修改模型会影响尚未发送的请求与响应示例，这是有意为之。
- 删除被引用的模型采用“警告后允许”，`model_id` 保留为失效引用，UI 标红并提供解除入口。
- 编辑器在引用状态下只读；用户点“编辑”时先确认解除引用，避免手改内容被发送时覆盖。
- 生成逻辑必须放在主进程，渲染层、MCP 与后续导出共用同一实现。
