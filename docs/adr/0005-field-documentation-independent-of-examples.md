# 字段文档独立于调用示例，未知规则明确标注

Status: accepted（2026-11-01）

接口文档需要让使用者了解请求与响应的完整字段规则，即使接口尚未发送过。字段文档与具体调用示例分别维护：示例可帮助识别结构和展示取值，但不能作为字段业务含义、必填或必有规则、可空性及完整枚举范围的唯一依据。

旧接口保留已有明确规则；缺失规则展示为“待补充”，不能静默当作可选、不可空或没有枚举限制。请求必填、响应必有、可为 null 与调试发送启用状态分别表达。这个选择保留了“不知道”与“明确不要求”的区别，代价是编辑、迁移与导出必须处理未说明状态，而不能只根据示例自动生成一份看似完整的契约。

本决策已由需求访谈第一轮确认；不指定底层存储结构，也不替代 ADR-0001 的模型引用实时解析约定。
