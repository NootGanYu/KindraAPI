# 内置 Agent 以草稿工作并单独授权保存定义

Status: accepted（2026-11-03）

内置 Agent 需要在连续操作中修改和测试接口或执行流程，同时用户可能正在编辑未保存内容。直接持久化每次修改会模糊工作中的草稿与已保存定义，也使用户难以控制持久化时机。

以草稿作为 Agent 默认工作版本，测试使用草稿；保存定义是独立的计划步骤，只有获批后才持久化定义。已批准计划明确包含保存步骤时，校验通过后可自动保存并关联候选；其他修改及退出快照保持待确认。变更提案在采纳前不属于草稿或已保存定义。记录待确认候选版本与正式保存定义是两个不同操作：候选记录不使定义正式保存。该选择要求应用能够管理草稿与已保存定义的并发变化，并在交互中清楚展示保存步骤。

这增加了草稿协调与冲突处理的复杂度，换取明确的持久化边界。执行快照、三方合并的具体实现仍需验证；远端结果未知时不自动重发，本决策不预设这些实现细节。
