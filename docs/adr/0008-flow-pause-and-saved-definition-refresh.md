# 执行计划暂停后采用已保存的接口定义

Status: accepted（2026-11-03）

执行计划默认使用运行快照。用户可请求暂停，界面显示正在暂停，待当前逻辑步骤完整结束后暂停；用户编辑并保存接口后，更新剩余步骤中受影响的接口定义，展示受影响步骤，并由用户手动继续。已完成步骤保留原版本及结果，运行变量继续传递；报告记录版本切换点。变更扩大已批准范围时重新确认授权。

该选择需要维护暂停边界、运行上下文和版本切换，增加实现复杂度，但可避免运行中无感混用版本，也避免为采用修改而重跑所有已完成请求。该决策已实现：UI 与 MCP 共用绑定环境的运行快照，完整逻辑步骤边界暂停后保留执行位置和运行变量；UI 可审阅剩余引用、解决覆盖冲突并确认范围变化，采用后手动继续。外部文件变化在发送前进入暂停审查，已完成请求不重放；报告保存版本切换和脱敏证据。实现与验证依据见 [AI 执行计划规格](../../.scratch/ai-execution-plan/spec.md)。
