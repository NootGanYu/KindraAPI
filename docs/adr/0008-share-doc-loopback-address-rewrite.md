# 分享文档在渲染时替换回环地址

接口定义里的绝对 URL 可能使用回环 host（`127.0.0.1`、`localhost`、`[::1]`、`0.0.0.0`），分享或导出后对访问者没有意义。我们决定只在渲染分享页与导出物时，把回环 host 换成分享者可被访问的内网地址，保留端口、路径与查询；不修改存储数据，也不改变分享页代理执行的原始地址。

**Considered Options**

- 导入/保存时归一化为 `{{baseUrl}}`：能治本，但会改写用户数据；同一项目可能有多个端口（如 8088 与 8888），需要拆成多个 Server。
- 用 `host_override` 替换：`host_override` 通常是文档域名，不一定是接口服务域名，容易把访问者引到错误的服务上。
- 执行链路一起替换：会改变 `Host` 头，并破坏“代理在分享者本机执行”的现有语义。

**Consequences**

- 文档展示地址与代理实际执行地址可能不同；在线页需要明确提示。
- 导出物拿到不同局域网时仍可能不可达。
- 分享页会公开分享者内网 IP（分享链接本身已经公开）。
- 识别不到可分享的内网地址时保留原样并提示，不编造地址。
