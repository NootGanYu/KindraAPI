# KindraAPI

## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `.scratch/` (local-only; not tracked on `code-only`).
The tracker guide lives on the `docs` branch at `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`,
`ready-for-agent`, `ready-for-human`, `wontfix`.
The label guide lives on the `docs` branch at `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the repo root; ADRs live under `docs/adr/` on the `docs` branch.
The domain guide lives on the `docs` branch at `docs/agents/domain.md`.
