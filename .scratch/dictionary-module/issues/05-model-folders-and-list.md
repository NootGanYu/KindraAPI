# 05: 模型目录与模型列表

**What to build:** 用户可以创建、重命名、删除模型目录与模型，在「全部模型」中查看名称、别名、创建人、创建时间、最后修改人、修改时间与目录；支持搜索、筛选与列显示设置。模型编辑器尚未实现时，打开模型可以展示明确的待实现占位。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 左侧树展示模型目录与模型，支持展开/折叠与搜索
- [ ] 可以新建目录、新建模型、重命名、删除；删除目录级联删除其下模型
- [ ] 全部模型页显示名称、别名、创建人、创建时间、最后修改人、修改时间与目录
- [ ] 支持按名称或别名搜索，按目录筛选
- [ ] 列设置支持显示/隐藏字段并保持设置
- [ ] 空态显示插画与「暂无数据」
- [ ] 创建人与修改人使用本地用户名或「本地」
- [ ] 打开模型时先显示编辑器占位，不报错
- [ ] smoke 覆盖目录/模型 CRUD、级联删除与列表查询
- [ ] UI 自动化覆盖新建目录/模型、搜索与列设置
