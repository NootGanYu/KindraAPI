# 10: MySQL 连接管理

**What to build:** 用户可以新建、编辑、删除 MySQL 连接，填写名称、说明、地址、端口、用户名、密码与数据库名，并在弹窗中查看和填写 SSH 配置；测试连接走直连并返回可读结果；SSH 配置只保存，不建立隧道，启用时明确提示后续支持。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 数据库管理页显示名称、数据库类型、说明与操作列，并有新建入口
- [ ] 连接弹窗包含名称、说明、数据库类型（仅 MySQL）、常规与 SSH 标签
- [ ] 常规配置包含地址、端口、用户名、密码与数据库名，密码支持显示/隐藏
- [ ] SSH 配置包含启用、host、port、用户名、密码、认证方式、私钥与 passphrase
- [ ] 连接配置按项目隔离保存，凭据按 ADR-0002 明文保存
- [ ] 测试连接执行直连并返回成功或可读的认证/网络错误，超时 8 秒
- [ ] SSH 启用时测试连接明确返回「隧道后续支持」，不静默走直连
- [ ] 可以编辑与删除连接；删除连接不影响已导入模型
- [ ] smoke 使用本机临时 MySQL 覆盖 CRUD、测试连接、失败错误与 SSH 提示
- [ ] UI 自动化覆盖新建、编辑、测试连接与 SSH 提示
- [ ] typecheck 与 build 通过
