# 04: 自定义字典 CRUD + 内置开关 + API 参数联想

**What to build:** 用户可以新建、编辑、删除自定义字段描述；项目级开关控制系统内置描述是否参与联想；API Header、Query、Path、Cookie 与 Body 表单参数的描述输入可以获得字典联想。自定义条目与内置条目在数据字典页按子标签区分。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 自定义子标签可以新建、编辑、删除条目，字段包含名称、类型、描述、备注与默认值
- [ ] 名称与描述必填校验明确；同名条目给出确认提示
- [ ] 自定义条目按名称排序并可搜索、分页
- [ ] 项目级开关写入项目元信息，关闭后内置描述不再参与联想，但仍可在系统内置页查看
- [ ] API Header / Query / Path / Cookie / Body 表单参数的描述输入支持字典联想
- [ ] 联想结果区分内置与自定义来源，选择后写入描述
- [ ] 删除条目后联想与列表同步更新
- [ ] smoke 覆盖自定义 CRUD、项目开关与联想数据源
- [ ] UI 自动化覆盖新建、编辑、删除与开关
- [ ] typecheck 与 build 通过
