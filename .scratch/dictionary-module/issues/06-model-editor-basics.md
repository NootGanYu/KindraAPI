# 06: 模型编辑器基础（可视化 + Raw + 预览）

**What to build:** 用户打开模型后，可以用可视化字段树编辑根节点、基础类型字段与基础数组，切换到 Raw JSON Schema 编辑，预览按 schema 生成的示例 JSON，并保存或删除模型；模型名称、别名与描述可编辑；模型字段描述支持字典联想。

**Blocked by:** 05, 01

**Status:** resolved

- [x] 模型标签打开后显示名称、别名、描述、保存与删除
- [x] 可视化字段树支持根节点、基础类型字段与基础数组的增删改
- [x] 字段描述输入支持字典联想
- [x] Raw 编辑支持 JSON Schema 文本与结构校验
- [x] Raw 与可视化切换时校验 schema，非法结构不写坏模型
- [x] 预览按共享生成能力展示示例 JSON
- [x] 保存后左侧树与全部模型列表同步更新
- [x] 关闭未保存标签时弹出确认
- [x] 「生成代码」「智能导入」以禁用态出现并标注后续支持
- [x] Mock 列以占位形式出现
- [x] smoke 覆盖保存/读取、Raw 校验与预览
- [x] UI 自动化覆盖字段编辑、Raw 切换、预览与保存
- [x] typecheck 与 build 通过
