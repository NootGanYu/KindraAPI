# 05: 进度与本地中断记录

**What to build:** 让用户在运行期间查看进度，并在退出或重启后查看已完成结果，不自动重放请求。

**Blocked by:** 04: 异步启动与查询 Run

**Status:** ready-for-agent

- [ ] UI 与 MCP 查询逐步显示进度和已完成部分结果，并持久化到本机。
- [ ] 新运行日志及快照证据不进入 Git，敏感值在展示和持久证据中脱敏。
- [ ] 使用 token、Cookie、嵌套字段和 console 样例验证 UI、MCP 与持久证据脱敏一致。
- [ ] 既有报告仍可读取，不批量迁移。
- [ ] 切换项目后 Run 保持原项目绑定，可返回查看；活动 Run 绑定的 Flow 不可删除。
- [ ] 退出时提示活动运行终止；重启显示中断和已有结果，不自动续跑或重发。
- [ ] 无法确认远端结果时显示结果未知，不假标普通失败。
- [ ] 真实存储和受控 loopback 测试验证逐步记录、退出重启及不重放；本票不要求取消能力。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
