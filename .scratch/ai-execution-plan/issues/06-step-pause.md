# 06: 完整步骤暂停并手动继续

**What to build:** 用户可在线性 Flow 请求暂停，在完整逻辑步骤结束后用原快照手动继续；MCP 可请求暂停但不能解除用户手动暂停。

**Blocked by:** 02: MCP 完整事件树与修订并发；03: 绑定环境的运行快照；04: 异步启动与查询 Run

**Status:** ready-for-agent

- [ ] UI 和 MCP 可请求暂停，立即显示正在暂停，当前完整逻辑步骤结束后进入暂停。
- [ ] 步骤边界包含步骤前脚本、接口前脚本、请求、接口后脚本、步骤后脚本及断言，组内不混用版本。
- [ ] 暂停后不发送后续请求；UI 可手动继续原快照，保存接口本身不触发继续。
- [ ] MCP 无解除用户暂停的工具；旧同步调用遇暂停返回 run_id 与真实状态而不挂起连接。
- [ ] 已完成步骤及运行变量保留，重复继续幂等，不重放已完成请求。
- [ ] 暂停 Run 占用活动锁；嵌套循环的暂停在票 07 完成前明确不可用，不假报已暂停。
- [ ] 受控延迟 loopback 和真实存储测试验证顺序、暂停时机、公开入口和兼容。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
