# 08: 暂停后保存并刷新剩余引用

**What to build:** 用户暂停后在 UI 编辑并主动保存 API，预览无冲突且未扩权的剩余引用更新，再手动继续；完整结果记录版本切换。

**Blocked by:** 05: 进度与本地中断记录；06: 完整步骤暂停并手动继续

**Status:** ready-for-agent

- [ ] 暂停期间用户可主动保存 API；保存不自动继续。
- [ ] 所有受影响的剩余引用均列出并可更新为新快照；已完成步骤保留原版本及结果。
- [ ] 界面显示实际生效请求与版本切换，手动继续后报告持久记录切换点。
- [ ] 保存失败、接口删除或 revision 并发变化时保持暂停；继续前重新校验 revision。
- [ ] 有步骤覆盖冲突或授权范围扩大时保持暂停，不在本票静默采用；分别留待票 09、10。
- [ ] Flow input 持久定义不因本轮刷新而隐式修改；token 和对象 ID 保留并校验前置条件。
- [ ] 与循环票独立实现，刷新接口能表示未来迭代；组合验证不重放已完成迭代。
- [ ] 真实存储、受控 loopback 和 UI 测试覆盖重复引用、保存、预览、继续与失败。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
