# 10: 执行范围变更审阅

**What to build:** 用户在暂停后采用新定义时，清楚审阅授权范围变化，扩权需明确确认才能继续。

**Blocked by:** 08: 暂停后保存并刷新剩余引用

**Status:** ready-for-agent

- [ ] 比较 method、origin、环境、脚本和文件范围并展示扩大项。
- [ ] 扩大原授权范围时要求用户明确确认，拒绝或关闭审阅保持暂停。
- [ ] 未扩大范围时不重复要求授权；保存本身不等于确认或继续。
- [ ] 用户确认后仍需手动继续，并记录审阅的版本及范围。
- [ ] 继续前重新校验权限和 revision；期间变化需重新审阅。
- [ ] 若存在步骤覆盖冲突而票 09 尚不可用，保持暂停，不通过授权确认绕过冲突。
- [ ] 真实存储、loopback 和 UI 测试验证扩大、未扩大、拒绝及并发变化。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
