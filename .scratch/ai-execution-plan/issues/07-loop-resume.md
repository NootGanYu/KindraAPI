# 07: 嵌套循环中暂停和恢复

**What to build:** 将步骤边界暂停和手动继续扩展到嵌套循环，保留迭代进度及变量，不重跑已完成操作。

**Blocked by:** 06: 完整步骤暂停并手动继续

**Status:** ready-for-agent

- [ ] UI 或 MCP 请求暂停后，嵌套循环在当前逻辑步骤完整结束后暂停。
- [ ] Run 保存恢复所需的游标、嵌套调用栈及变量，从正确迭代继续。
- [ ] 运行实例使用稳定 event ID 和 iteration 标识；已完成迭代不会重发请求。
- [ ] 重复继续幂等，已提取 token 和对象 ID 保持可用。
- [ ] 条件及分组内部可在逻辑步骤边界暂停；嵌套迭代使用完整路径，避免相同 event 在不同外层轮次碰撞。
- [ ] 原有条件、循环和脚本行为不因暂停支持改变。
- [ ] 为后续剩余步骤新快照预留迭代识别，已完成迭代不被重写，不依赖票 08 实现。
- [ ] 真实存储和受控 loopback 测试覆盖嵌套循环及 UI 继续。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
