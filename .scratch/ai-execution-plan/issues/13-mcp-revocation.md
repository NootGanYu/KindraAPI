# 13: 运行期间 MCP 权限撤销

**What to build:** 在 MCP 发起的 Run 中持续执行现有项目和工具权限策略，权限撤销后阻止后续操作，同时用户仍可在 UI 停止。

**Blocked by:** 12: 有界取消与远端结果未知

**Status:** ready-for-agent

- [ ] 创建和更新保持现有 write 约束；启动要求 execute，查询要求只读权限及项目允许。
- [ ] 每次 MCP 控制及继续前重新校验 enabled、项目允许列表和相应权限。
- [ ] MCP 权限撤销后，由 MCP 发起的 Run 不再执行后续步骤，并显示明确状态。
- [ ] 撤权不影响 UI 实际取消和停止 Run；已完成请求不被重放。
- [ ] UI 与 MCP 使用各自身份及策略，不通过伪造 MCP 配置获取权限。
- [ ] MCP 无自动解除用户手动暂停的能力；无暂停且权限有效的旧调用保持兼容。
- [ ] 至少一个真实 TCP 或 stdio MCP 测试结合 loopback 和真实存储验证撤权、后续阻止和 UI 取消。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
