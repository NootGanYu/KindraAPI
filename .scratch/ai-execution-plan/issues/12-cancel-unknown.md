# 12: 有界取消与远端结果未知

**What to build:** 用户和经授权 MCP 可取消活动或暂停的 Run，并如实看到已发送请求可能产生的未知远端结果。

**Blocked by:** 05: 进度与本地中断记录；06: 完整步骤暂停并手动继续

**Status:** ready-for-agent

- [ ] UI 和 cancel_flow_run 可有界请求取消活动或暂停 Run，返回真实状态；仅在本地任务停止推进且在途工作妥善结束或隔离后释放活动锁，避免与新 Run 重叠。
- [ ] 已发送请求不能保证撤销时明确表达远端结果未知，不伪称回滚。
- [ ] 取消不自动重试或重放，已完成部分结果保留并可在重启后查看。
- [ ] 重复取消安全且不会重复发请求；取消与失败、用户暂停分别表达。
- [ ] 连接断开或超时不重新启动 Run，后续可按 run_id 查询。
- [ ] 权限变化时 UI 仍可执行停止能力，不依赖 MCP 权限。
- [ ] 受控 loopback、真实存储和 UI/MCP 测试覆盖进行中请求及暂停取消。
- [ ] 执行本票相关类型检查及 build，保持现有检查通过。
