**What to build:** 用户在暂停后审阅新 API 与步骤覆盖的冲突，明确选择本轮实际请求，再手动继续。

**Blocked by:** 08: 暂停后保存并刷新剩余引用

**Status:** ready-for-agent

- [ ] 新 API 修改被步骤覆盖的字段时展示冲突，body 整体覆盖亦展示；未冲突覆盖保留。
- [ ] 用户可逐项选择新 API 值或保留步骤覆盖，并看到实际生效请求。

- [ ] 选择仅写本 Run revision，不隐式改持久 Flow input；后续运行读取其原定义。

- [ ] 授权范围扩大时继续保持暂停，票 10 完成前不得借冲突选择绕过授权。
- [ ] 真实存储和 loopback/UI 测试覆盖字段、body、解决与未解决状态。
